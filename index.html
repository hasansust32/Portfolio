LLM application

Local LLM Chat API

A private chat service that runs on a local model and replies in Bangla or English.

  • Streams replies token by token as NDJSON, or returns one JSON response
  • Keeps the last 20 messages of each session as context
  • Exports conversations as JSON or Markdown
  • Runs with one Docker Compose command, with health checks and unit and API tests that don't need Ollama

Bangla NLP research

Bangla Fake News Detection

A full pipeline for spotting fake news in Bangla, from dataset to mobile app. Published with IEEE.

  • Benchmarks classical ML, LSTM, RNN and Bangla BERT models
  • The RNN reached 96.55% accuracy; Bangla BERT reached an F1 score of 0.96
  • Predictions served through a Flask API to a Flutter mobile app
  • The work was adopted by a media agency

Robotics simulation

Autonomous Robot Simulation

A Unity robot that drives itself along a track, steering around obstacles and powering up slopes.

  • Raycast sensors detect obstacles, slopes and road edges
  • Steering angle and motor force adjust from the sensor readings
  • Uses Unity's Rigidbody and WheelCollider physics
  • Built for the Artificial Life with Robotics module of my MSc

Agent-based modelling

Disease Spread Simulation

A NetLogo model for testing how public-health measures change the way a disease spreads.

  • Two regions of agents, each with its own population and starting conditions
  • Travel restrictions, social distancing and self-isolation switch on or off mid-run
  • Live monitors for infections, deaths and immunity
  • Sliders for infection rate, survival rate, immunity and illness duration
  • NetLogo
  • Agent-based modelling
