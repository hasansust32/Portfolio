# hasansm.com: Personal Portfolio

Source for my portfolio site, **[www.hasansm.com](https://www.hasansm.com/)**, served by GitHub Pages from this repository.

## What's here

| File | Purpose |
|---|---|
| `index.html` | The entire site in one self-contained file: HTML, CSS, JavaScript and inline images, with no build step or external framework |
| `CV_SM_Hasan.pdf` | Downloadable CV linked from the site |
| `CNAME` | Custom domain for GitHub Pages (`www.hasansm.com`) |

The page has sections for About, Projects, Repositories, Research (with per-paper result charts), Experience, Skills, Education and Contact.

## Running locally

No tooling is needed; open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Deployment

GitHub Pages publishes the `main` branch. The custom domain is set in **Settings → Pages** and DNS is managed at the domain registrar.
